# Jelvan Folder Portfolio Design

This folder contains the standalone HTML portfolio design supplied for the Jelvan portfolio.

## Entry point

- `index.html` — standalone portfolio design. The file is intended to remain unchanged; only its filename is normalized to `index.html`.

## Usage

Open `index.html` in a modern web browser to preview the design. Keep any referenced local assets and paths intact when moving or hosting the file.

## Notes

- This is a self-contained design artifact, separate from the main portfolio application source.
- No visual, content, or behavior changes are intended as part of this folder setup.
